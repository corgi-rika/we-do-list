# WeDoList

グループでのタスク共有における「抜け漏れ」「進捗確認の手間」「担当状況の見えづらさ」を解消する ToDo アプリケーションです。

---

## アプリ概要

**WeDoList** は、グループメンバー間でタスクを共有・管理できる Web アプリケーションです。

個人用の ToDo アプリではなく、家族・パートナー・友人など身近な少人数グループで「誰が何をやるか」「どこまで終わっているか」を見える化することを目的としています。LINE や口頭だけではタスクが流れてしまい、誰が担当しているのか・何が終わっているのかが分かりにくくなる課題を解決するために作成しました。

---

## 本アプリの特徴

グループ・カテゴリ・タスク・達成率を一体化し、複数人でのタスク共有における抜け漏れを防ぐ設計を重視しました。

- グループごとにタスクを共有・管理できる
- 招待コードを使ってメンバーがグループに参加できる
- カテゴリごとにタスクを整理できる
- タスクの完了状況をプログレスバーとパーセンテージで確認できる
- リーダー権限により、カテゴリ編集・グループ管理などの操作を制限できる
- PC・スマートフォン・タブレットで崩れずに操作できる

---

## 開発の背景

家族や身近な人と予定や準備を進める中で、LINE や口頭だけではタスクが流れてしまい、管理が難しいと感じたことがきっかけです。

複数人でタスクを進める場面では「誰が何を完了したのか」「どの作業が残っているのか」が見えづらくなることがあります。

そこで、グループごとにタスクを共有し、カテゴリ別に整理しながら完了状況や達成率を一目で確認できるアプリを作成しました。

## 要件定義

### 対象ユーザー

- 家族・パートナー・友人など身近な少人数グループでタスクを共有・管理したい人
- LINE や口頭だけのタスク共有に限界を感じているユーザー
- 複数人の作業進捗をまとめて確認したいユーザー

### 解決したい課題

| #   | 課題                                               |
| --- | -------------------------------------------------- |
| 1   | グループ内でタスクの抜け漏れや重複が起きる         |
| 2   | タスクが整理されておらず、何をすべきか把握しにくい |
| 3   | メンバーごとの完了状況や全体の進捗が見えづらい     |
| 4   | 共有ツールが分散し、タスクの確認に手間がかかる     |

### 実現したいこと

| #   | 内容                                                 |
| --- | ---------------------------------------------------- |
| 1   | グループを作成・参加し、メンバーとタスクを共有できる |
| 2   | タスクをカテゴリ別に整理できる                       |
| 3   | タスクの完了状況を記録できる                         |
| 4   | グループ全体の達成率を視覚的に確認できる             |
| 5   | 権限に応じて操作できる範囲を分けられる               |

## 実装済み機能

### 認証機能

| 機能             | 内容                                               |
| ---------------- | -------------------------------------------------- |
| ユーザー新規登録 | メールアドレスとパスワードで新規登録できます       |
| ログイン         | 登録済みユーザーがログインできます                 |
| ログアウト       | ログイン中のユーザーがログアウトできます           |
| セッション管理   | Supabase Auth によりログイン状態を管理します       |
| アクセス制限     | 未ログインユーザーは保護ページにアクセスできません |

### グループ管理機能

| 機能                 | 内容                                                                   |
| -------------------- | ---------------------------------------------------------------------- |
| グループ作成         | 新しいグループを作成できます                                           |
| リーダー自動登録     | グループ作成者を自動的にリーダーとして登録します                       |
| グループ参加         | 招待コードを入力して既存グループに参加できます                         |
| メンバー一覧表示     | グループに参加しているメンバーを一覧で確認できます                     |
| メンバー管理         | リーダーのみメンバー管理を行えます                                     |
| グループ設定・削除   | リーダーのみグループ設定の変更・削除ができます                         |
| メンバー数の上限管理 | グループ参加時に、設定した上限人数を超えて参加できないように制御します |

### カテゴリ管理機能

| 機能               | 内容                                       |
| ------------------ | ------------------------------------------ |
| カテゴリ作成       | グループごとにカテゴリを作成できます       |
| カテゴリ編集       | リーダーのみカテゴリ名を編集できます       |
| カテゴリ削除       | リーダーのみカテゴリを削除できます         |
| カテゴリ別表示     | タスクをカテゴリごとに整理して表示できます |
| アコーディオン表示 | カテゴリごとにタスク一覧を開閉できます     |

### タスク管理機能

| 機能                   | 内容                                         |
| ---------------------- | -------------------------------------------- |
| タスク作成             | カテゴリに紐づけてタスクを作成できます       |
| タスク編集             | タスク内容を編集できます                     |
| 完了・未完了切り替え   | タスクの状態を完了・未完了に切り替えられます |
| 完了者・完了日時の記録 | 誰がいつ完了したかを記録・表示します         |
| タスク削除             | リーダーのみ、完了済みタスクを削除できます   |

### 統計・マイページ機能

| 機能               | 内容                                                     |
| ------------------ | -------------------------------------------------------- |
| 達成率表示         | タスク達成率をプログレスバーとパーセンテージで表示します |
| タスク数表示       | 完了済みタスク数・全体タスク数を表示します               |
| 未完了タスク数表示 | カテゴリごとの未完了タスク数を表示します                 |
| マイページ         | 参加グループ数・未完了タスク数を確認できます             |
